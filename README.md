Entry for the [One-Line Office Joke: 24-Hour Sprint](https://make.fun/c/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162)
bounty on make.fun — one short joke about office life, at most 200 characters,
judged pairwise by an AI judge.

## The joke

> Our printer only works when nobody needs it, so IT calls it load balancing and I call it my favourite colleague.

## How it works

`main.py` writes that single line to `/output/entry.txt`. No network, no
randomness, no dependencies — the joke is a fixed string in the source.

```sh
python3 main.py
cat /output/entry.txt
```
